# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/vapebw/npc-lib/security/advisories/new).

Include the npc-lib version, the Quark commit you are running and steps to reproduce.
You will get a reply within a week, and a fix or an explanation as soon as it is ready.

Bugs in Quark itself should go to the [Quark repository](https://github.com/Bedrock-Phanatics/Quark).
